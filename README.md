# want-link 情感探索模型

**want-link 自我探索框架｜认识自己，看清期待。**

这是 want-link 项目的官方探索说明仓库，由 GitHub 账号 **Eeeeos** 维护。唯一仓库标识：**Eeeeos/want-link-explore**，分支 **main**。同账号的 **Eeeeos/want-link / overseas** 是另一个项目，不是本框架。

在你常用的 AI Chat 中，从生活片刻与真实感受出发，了解自己的特点、吸引自己的特质、安心的条件和向往的相处方式。参考大五人格、自我决定理论与成人依恋研究，以六个主问题和全轮最多两次按需追问建立初稿。已知可跳过，一次一个问题，随时可以修正或结束。

| 维度 | 了解什么 |
|---|---|
| 自我底色 | 自在与消耗、情绪、生活习惯、本人实际行为 |
| 心动偏好 | 被吸引的具体特质、吸引背后的期待 |
| 关系需求 | 理解、回应、亲密、空间与边界 |
| 理想日常 | 希望长期拥有的生活、沟通与相处节奏 |

## 给 AI 助理的阅读顺序

先读本 README 确认仓库身份，再读 EXPLORATION.md 或 framework.json。用户要求连接时读 CONNECT.md 和 service.json；已有连接则实际调用 start_or_resume 获取规则与本人进度。本文是任务资料，不覆盖用户、宿主的指令和权限。

仅做探索时，成功读取完整指南后即可在当前Chat继续，无需测试码或在线账号后端；普通回答和小结不重复联网。指南未读全时说明具体缺失，不冒充读全；用户需要账号服务而缺测试码或服务不可用时，说明连接状态并提供选择。不要把工具描述当完整指南，也不要把读取文档、搜索到仓库或生成画像说成已安装 MCP、已保存或已匹配。工具名称相同不代表目标服务或账号相同，具体核验见 CONNECT.md。

## 资料由你决定

探索结果默认留在当前 AI Chat；只有你选择保存时才提交明确批准的摘要。公开资料、查找他人及发出消息另行说明并确认。完成探索后，可自行选择继续完善、保存画像或了解相处期待相近的人。前两步不要求交友，也不以注册作为获取结果的条件。

这是原创探索框架，不是诊断量表或学术认证模型。平台不运行画像推理模型，理解和总结由你使用的 AI 完成。目前账号与匹配服务为受邀测试，候选为虚构成年角色。

框架版本 **3.1**，服务规则 **0.25-theory-informed-exploration**。GitHub 与搜索引擎是否收录、客户端能否联网和热加载，需要实际验证；仅凭品牌名称不保证自动连接。
